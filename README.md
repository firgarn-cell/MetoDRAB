# MetoDRAB

Методическая работа кафедры информационных систем (АНПОО «СИЭУиП», корпус СП7).

## Состав

- `УчебныйПлан/` — учебный план группы **ИС 25/11**, квалификация **Программист** (09.02.07).
- `РабочиеПрограммы/` — рабочие программы профессиональных модулей **только для программиста**:
  - ПМ.01, ПМ.02, ПМ.04 — пересобраны под программиста
  - `ПМ_11_…docx` — сверен с оригиналом `ПМ.11 Разработка, администрирование и защита баз данных.docx` (темы, практики, ЗУН), часы и квалификация — по учебному плану ИС 25/11
- `data/pm_curriculum_is2511.json` — часы и разбивка лекций/практики по семестрам из учебного плана
- `scripts/generate_pm_work_programs.py` — генерация РП ПМ.01/02/04
- `scripts/generate_pm11_programmer.py` — сборка ПМ.11 из оригинала + часов плана

## Важно

В РП ПМ убраны чужие квалификации (администратор БД, тестировщик, технический писатель и др.).  
Для каждого МДК указано, сколько часов лекций и практических занятий приходится на семестр — по учебному плану ИС 25-11.
