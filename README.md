# MetoDRAB

Методическая работа кафедры информационных систем (АНПОО «СИЭУиП», корпус СП7).

## Состав

- `УчебныйПлан/` — учебный план группы **ИС 25/11**, квалификация **Программист** (09.02.07).
- **`РабочиеПрограммы/Готовые_ИС2511_программист/`** — готовые РП ПМ для квалификации **Программист** (группа ИС 25/11):
  - ПМ.01, ПМ.02, ПМ.04, ПМ.11 + сводка часов
- `РабочиеПрограммы/оригиналы/` — исходные файлы для сверки (в т.ч. оригинал ПМ.11)
- `data/pm_curriculum_is2511.json` — часы и разбивка лекций/практики по семестрам
- `scripts/` — генераторы РП

## Важно

В готовых РП ПМ — только квалификация «Программист».  
Разбивка часов — **как в учебном плане**: семестры в шапке таблицы, элементы ПМ слева, на пересечении лекции / практические занятия (для практик — часы / недели).
